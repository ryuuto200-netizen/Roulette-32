# ORBIT 32 — Roulette-32

1〜32から数字をひとつ選ぶ、ブラウザー用のランダム抽選ホイールです。

## 使い方
- **スタート**を押すとホイールが回転します。
- 回転中に**ストップ**を押すと、マーカーの位置で数字が選ばれます。
- 数字は毎回1〜32から等しい確率で選ばれ、同じ数字が続けて出ることもあります。
- 直近4回の結果を画面内に表示します。

## GitHub Pagesで公開する場合
リポジトリの Settings → Pages で、公開元に main ブランチのルートを指定してください。ビルド工程は不要です。

## 技術メモ
HTML・CSS・JavaScriptだけで動作し、外部ライブラリや画像に依存しません。抽選にはブラウザーの crypto.getRandomValues() を使用します。
